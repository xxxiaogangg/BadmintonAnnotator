# 羽毛球技战术分析与标注工具 v2.2.2

![App Screenshot](https://raw.githubusercontent.com/username/repo/main/screenshot.png) <!-- 建议替换成你的应用截图 -->

这是一个功能强大的桌面应用程序，专为羽毛球爱好者、教练员和数据分析师设计，用于对羽毛球比赛视频进行深度技战术标注和分析。

本工具基于 Python 和 PyQt6 构建，拥有高性能的视频播放核心和流畅的交互体验，旨在将繁琐的视频分析工作变得高效而直观。

---

## ✨ 核心功能

*   **高性能视频播放**:
    *   流畅播放高清、大体积的视频文件，UI界面永不卡顿。
    *   支持倍速播放 (`0.5x`, `1.0x`, `2.0x`, `4.0x`)。
    *   **精准控制**: 支持单帧步进，以及可自定义的快速跳转（`10帧`, `1秒`, `5秒`）。

*   **多维度事件标注**:
    *   **结构化记录**: 按“局(Set)”和“回合(Rally)”组织比赛，自动处理羽毛球计分规则（含Deuce）。
    *   **高效打点**: 支持“先打点，后完善”的工作流。先快速标记击球时间点，后续再补充细节。
    *   **技术细节**: 支持标注正反手、技术大类（如杀球、吊球）、技术小类以及得分/失误原因。

*   **智能审阅与导航 (新功能)**:
    *   **右侧多功能面板**: 通过下拉框在“球与运动员”、“击球事件”和“击球事件审阅”页面间切换，界面更整洁。
    *   **审阅模式**: 专门的面板用于统计和跳转“待定”或“不适用”的事件，帮助用户快速补全缺失的技术细节，确保数据完整性。
    *   **[新] 横屏审阅布局**: 提供“击球事件审阅（横屏）”选项，将事件浏览器置于底部全宽显示，视频与控制区并排，优化宽屏下的审阅体验。
    *   **事件微调**: 支持使用快捷键 (`Shift` + `←/→`) 微调当前选中事件的帧号，无需删除重录。

*   **精细化对象标注**:
    *   在视频任意帧使用**矩形框**标注球员，或使用**标记点**标注羽毛球。
    *   支持对象的选择、移动、缩放和删除，所见即所得。

*   **健壮的数据管理**:
    *   **自动加载/恢复**: 自动加载同名标注文件；检测到未保存的自动备份时提示恢复。
    *   **[新] 会话记忆**: 自动记录并提示恢复上次打开的视频文件，方便快速继续工作。
    *   **[新] 拖拽加载**: 支持拖拽视频文件直接打开；在已加载视频后可拖入 `JSON` 标注文件进行加载。
    *   **自动备份**: 每分钟自动保存当前进度，防止数据丢失。
    *   数据以通用 `JSON` 格式存储，便于二次开发和分析。

## 📖 使用指南

### 1. 界面布局
*   **左侧**: 视频播放区及播放控制条。
*   **右侧顶部**: 功能切换区。通过下拉框选择：
    *   **球与运动员**: 用于画框、画点标注。
    *   **击球事件**: 查看比分，使用按钮添加比赛事件。
    *   **击球事件**: 查看比分，使用按钮添加比赛事件。
    *   **击球事件审阅**: 快速查找未完成标注的事件（待定/不适用）。
    *   **击球事件审阅（横屏）**: 切换到上下布局模式，事件列表横向铺开在底部。
*   **右侧底部**: 事件浏览器（Event Tree），以树状结构显示整场比赛的事件流。双击任意节点可编辑详情。

### 2. 推荐工作流
1.  **加载视频**: 打开视频文件（可直接拖拽视频到主窗口），初始化比赛信息（球员姓名）。
2.  **粗略打点**:
    *   跟随视频播放，使用快捷键 `S` (局开始) -> `R` (发球) -> `I` (击球...) -> `E` (死球) 进行标记。
    *   此时无需关注技术细节，程序会自动创建“待定”事件。
3.  **精细调整**:
    *   如果发现按键慢了，选中事件列表中的条目，按 `Shift` + `←` 修正帧号。
4.  **补全细节 (审阅)**:
    *   切换右侧面板到 **“击球事件审阅”**。
    *   点击“下一个待定”按钮，自动跳转到未标记技术的事件。
    *   按 `Enter` 键打开对话框，选择正反手及技术动作（如：正手-杀球）。
    *   重复此步骤直到所有“待定”项归零。

## 🛠️ 从源码运行 (开发者指南)

1.  **克隆仓库**:
    ```bash
    git clone https://github.com/username/repo.git
    cd badminton_annotator
    ```
2.  **环境配置**:
    建议使用 Python 3.9+。
    ```bash
    # 创建虚拟环境
    python -m venv venv
    
    # 激活虚拟环境
    # Windows:
    venv\Scripts\activate
    # macOS / Linux:
    source venv/bin/activate
    ```
3.  **安装依赖**:
    ```bash
    pip install -r requirements.txt
    ```
    *确保已安装 `PyQt6` 和 `opencv-python`。*
4.  **运行**:
    ```bash
    python main.py
    ```
