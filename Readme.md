# 羽毛球技战术分析与标注工具 v2.0

![App Screenshot](https://raw.githubusercontent.com/username/repo/main/screenshot.png) <!-- 建议替换成你的应用截图 -->

这是一个功能强大的桌面应用程序，专为羽毛球爱好者、教练员和数据分析师设计，用于对羽毛球比赛视频进行深度技战术标注和分析。

本工具基于 Python 和 PyQt6 构建，拥有高性能的视频播放核心和流畅的交互体验，旨在将繁琐的视频分析工作变得高效而直观。

---

## ✨ 核心功能

*   **高性能视频播放**:
    *   流畅播放高清、大体积的视频文件，UI界面永不卡顿。
    *   支持倍速播放 (`0.5x`, `1.0x`, `2.0x`, `4.0x`)。
    *   精准的逐帧移动和可自定义的快速跳转（`10帧`, `1秒`, `5秒`）。

*   **多维度事件标注**:
    *   **比赛结构化**: 支持按“局(Set)”和“回合(Rally)”来组织比赛，结构清晰。
    *   **智能计分**: 自动处理羽毛球计分规则，包括Deuce和30分封顶。
    *   **技术细节**:
        *   为每一个**发球**（回合开始）标注详细的技术动作（如：发高远球）。
        *   为每一个**击球(Shot)**标注精细的技术分类（正反手、技术大类、技术小类）。
        *   为每一个**回合结束**标注得分方式或失误原因。

*   **精细化对象标注**:
    *   在视频的任意帧，使用**矩形框**标注球员。
    *   使用**标记点**标注羽毛球的精确位置。
    *   所有标注对象均支持**选择、移动、缩放和删除**。

*   **高效工作流**:
    *   **“先标记，后编辑”**: 支持快速在时间轴上打点标记所有击球，稍后再回头逐个双击补充技术细节。
    *   **智能辅助**:
        *   自动推断发球方（仅需在每局0-0时手动指定一次）。
        *   在补充击球标注时，自动推断击球员。
    *   **全面的快捷键支持**，让资深用户摆脱鼠标束缚。

*   **健壮的数据管理**:
    *   **自动加载**: 打开视频时，自动查找并加载同目录下的标注文件。
    *   **自动备份**: 每分钟自动保存当前工作进度到 `.autosave.json` 文件，防止意外情况导致数据丢失。
    *   **智能恢复**: 程序启动时若发现有未保存的备份，会提示用户恢复工作。
    *   所有标注数据以人类可读的 `JSON` 格式保存。

## 🚀 快速开始 (用户指南)

1.  **下载**: 从 [发布页面](https://github.com/username/repo/releases) 下载适用于您操作系统的最新版本 (`.app` for macOS, `.exe` for Windows)。
2.  **运行**:
    *   **macOS**: 将 `BadmintonAnnotator.app` 拖入“应用程序”文件夹，然后双击打开。如果提示“无法验证开发者”，请右键点击应用图标，选择“打开”，然后再次确认。
    *   **Windows**: 双击 `BadmintonAnnotator.exe` 即可运行。
3.  **开始标注**:
    *   通过菜单栏 “文件” -> “打开视频...” 加载一个比赛视频。
    *   首次标注会弹出“设置比赛信息”对话框，请填写球员、赛事等信息。
    *   使用快捷键 (`S`, `R`, `I`, `E`) 或界面按钮，在时间轴上标记比赛事件。
    *   双击事件树中的“待定”项，补充详细的技术信息。
    *   在需要时，使用 `W` (框选) 和 `A` (标记点) 键切换模式，在视频画面上进行对象标注。
    *   记得使用 `Ctrl` + `S` 随时保存你的工作！

## 🛠️ 从源码运行 (开发者指南)

1.  **克隆仓库**:
    ```bash
    git clone https://github.com/username/repo.git
    cd badminton_annotator
    ```
2.  **创建虚拟环境**:
    ```bash
    python3 -m venv venv
    source venv/bin/activate  # macOS / Linux
    # venv\Scripts\activate  # Windows
    ```
3.  **安装依赖**:
    ```bash
    pip install -r requirements.txt
    ```
4.  **运行**:
    ```bash
    python main.py
    ```
